# 📚 Documentación del Proyecto Talky

Esta carpeta contiene toda la documentación del proyecto organizada por categorías.

## 📁 Estructura

### `/setup` - Configuración e Instalación
Guías para configurar el entorno de desarrollo:
- `CONFIGURAR_JAVA.md` - Configuración de Java y JAVA_HOME
- `DOCKER_SETUP.md` - Configuración de Docker y PostgreSQL
- `CONFIGURACION_VARIABLES_ENTORNO.md` - Variables de entorno del backend
- `CONFIGURACION_COGNITO.md` - Configuración de AWS Cognito en el frontend
- `CREAR_USUARIO_ADMIN.md` - Cómo crear o actualizar un usuario administrador
- `SOLUCION_ERRORES_RED.md` - Solución de problemas de conexión y autenticación

### `/api` - Documentación de API
Documentación sobre la API y roles:
- `FRONTEND_API_DOCUMENTATION.md` - Documentación de la API para el frontend
- `ROLES_GUIDE.md` - Guía de roles y permisos

### `/desarrollo` - Desarrollo
Documentos relacionados con el desarrollo del proyecto:
- `DESIGN_PLAN_COURSES_EXAMS.md` - Plan de diseño de cursos y exámenes
- `ROLES_IMPLEMENTATION_SUMMARY.md` - Resumen de implementación de roles
- `FRONTEND_ROLES_IMPLEMENTATION.md` - Implementación de roles en frontend
- `GUIA_DE_PRUEBAS.md` - Guía de pruebas

### `/analisis` - Análisis
Análisis y reportes del proyecto:
- `ANALISIS_PROYECTO.md` - Análisis completo del proyecto
- `CAMBIOS_SEGURIDAD.md` - Cambios de seguridad realizados

## 🚀 Inicio Rápido

1. **Configuración inicial:**
   - Lee `setup/CONFIGURAR_JAVA.md` para configurar Java
   - Lee `setup/DOCKER_SETUP.md` para configurar Docker
   - Lee `setup/CONFIGURACION_VARIABLES_ENTORNO.md` para el backend
   - Lee `setup/CONFIGURACION_COGNITO.md` para el frontend

2. **Arrancar el proyecto:**
   - Ejecuta `scripts/start-dev.bat` desde la raíz del proyecto

3. **Documentación de API:**
   - Consulta `api/FRONTEND_API_DOCUMENTATION.md` para ver los endpoints disponibles

## 📝 Notas

- Toda la documentación está centralizada aquí para facilitar el mantenimiento
- Los README.md en `backend/` y `frontend/` contienen información específica de cada parte
- El README.md principal del proyecto está en la raíz
